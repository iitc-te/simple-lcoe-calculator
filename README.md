# Simple LCOE Calculator

**Utility-Scale Power Generation**

An interactive web tool for estimating the Levelized Cost of Electricity (LCOE) of a utility-scale power plant, accounting for construction costs, economic lifetime, capacity factor, O&M, fuel, taxes, and discount rate.

🔗 **Live tool:** [iitc-te.github.io/simple-lcoe-calculator](https://iitc-te.github.io/simple-lcoe-calculator/)
